# C-001 — Project Scaffold, Health Endpoint, Live OpenAPI Spec & Vertical Slice

status: done
deps: none

## Scope

1. Khởi tạo cấu trúc project React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons + PWA plugin.
2. Thiết lập endpoint `/healthz` trả về `{ status: "ok", version: "1.0.0", timestamp: string }`.
3. Xây dựng endpoints quản lý phòng: `POST /api/rooms` (tạo phòng) và `GET /api/rooms/:code` (lấy thông tin phòng).
4. Phục vụ tài liệu OpenAPI JSON tại `/api/openapi.json` chứa hợp đồng theo `flow/05-contract.md`.
5. Xây dựng Vertical Slice: Một giao diện tạo phòng và tham gia phòng bằng mã PIN 6 số kết nối với backend API.
