# C-003 — AI Voice-to-Food Parser & Smart Recipe Suggester Endpoints

status: done
deps: C-002

## Scope

1. Tích hợp Google Gemini 2.5 Flash API phục vụ endpoint `POST /api/ai/parse-voice`:
   - Tiếp nhận chuỗi `transcript` tiếng Việt (ví dụ: *"Thịt bò 3 lạng ngăn đông túi zip xanh"*).
   - Trả về JSON `ParsedFoodItem` gồm `name`, `quantity`, `compartment`, `container_tag`, `shelf_life_days`.
   - Có fallback rule-based regex nếu mất mạng hoặc offline.
2. Xây dựng endpoint `POST /api/ai/suggest-recipes`:
   - Đọc danh sách thực phẩm `ACTIVE` trong tủ phòng trọ, phân loại các món sắp hết hạn (`COOK_SOON`).
   - Gọi Gemini sinh 2-3 gợi ý món ăn thuần Việt phù hợp sinh viên/người đi làm (nấu nhanh 15-20p, chỉ rõ nguyên liệu tận dụng & cách làm 3 bước).
3. Cập nhật OpenAPI spec `/api/openapi.json` chứa 2 endpoints AI.
