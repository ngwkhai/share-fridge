# C-008 — Enhanced Security, Room Passcode & Session Token Auth

status: done
deps: C-007

## Scope

1. Bổ sung trường `passcode_hash` và `salt` cho phòng và endpoint `POST /api/auth/create-room`, `POST /api/auth/join-room`, `POST /api/auth/verify-token`.
2. Tạo Token Service sinh và xác thực HMAC Session Token (`X-Room-Token`).
3. Xây dựng Rate Limiting middleware (tối đa 5 lần thử sai / 15 phút trên mỗi IP).
4. Cập nhật UI màn hình đăng nhập / tạo phòng có mật khẩu bí mật (Passcode 4-6 số) và lưu Session Token trong LocalStorage.
