# C-006 — Frontend Integration, Voice/Camera Hooks & Realtime Synchronization

status: done
deps: C-002, C-003, C-004, C-005

## Scope

1. Tích hợp API Client & State Management cho React PWA:
   - Gọi CRUD endpoints cho Food Items và Shopping List.
   - Kết nối Supabase Realtime channel theo `room_code` để cập nhật danh sách tức thì khi bạn cùng phòng thay đổi.
2. Tích hợp Web Speech API hook (`useVoiceInput`):
   - Nhận diện giọng nói tiếng Việt thời gian thực.
   - Gửi text đến AI parser và tự động điền form Quick Add.
3. Tích hợp Camera & Client-side Image Compressor (`useCamera`):
   - Chụp ảnh từ camera điện thoại, nén ảnh xuống < 100KB qua Canvas / browser-image-compression.
   - Upload ảnh lên storage và hiển thị thumbnail tức thì.
4. Tích hợp AI Recipe Suggester hook:
   - Gọi gợi ý món và hỗ trợ action 1 chạm "Nấu món này" (đánh dấu nguyên liệu tương ứng thành `CONSUMED`).
5. Tích hợp Web Push prompt & Service worker notification trigger.
