# C-002 — Food Items & Shopping List Backend Endpoints

status: done
deps: C-001

## Scope

1. Xây dựng Data Service & API Endpoints cho quản lý thực phẩm:
   - `GET /api/foods?room_code=...` (tính toán `days_remaining` và `status`: FRESH, COOK_SOON, EXPIRED).
   - `POST /api/foods` (thêm món mới theo `CreateFoodDto`).
   - `PATCH /api/foods/:id/consume` (đánh dấu đã ăn/đã nấu).
   - `DELETE /api/foods/:id`.
2. Xây dựng Data Service & API Endpoints cho danh sách đi chợ:
   - `GET /api/shopping-items?room_code=...`.
   - `POST /api/shopping-items`.
   - `PATCH /api/shopping-items/:id/toggle`.
   - `DELETE /api/shopping-items/:id`.
3. Đảm bảo tất cả endpoints phản ánh đầy đủ trên live OpenAPI spec `/api/openapi.json`.
